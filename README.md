# BeerpongFlutter

A small Flutter web app for managing beer pong players, teams, competitions, and games. Mainly created for using with smart phones. It is a recreation of my beerpong app i developed for android.

The project is available under https://larimei.github.io/BeerpongFlutter/

This project is mainly built as a learning project to improve my skills in:

- Flutter and Dart
- App architecture and state management
- UI development
- Programming with OpenAI Codex and Skills

## Features

- Create and manage players
- View player details and statistics
- Create and manage teams
- Create competitions based on round robin and k.o.
- Manage games within competitions

## Purpose

The main goal of this project is not to build a production-ready beer pong platform, but to learn Flutter and Supabase and improve my programming workflow by developing the application together with Codex, Agents and Skills by Matt Pocock.

## Running the Project

```bash
flutter pub get
flutter run -d chrome
```
